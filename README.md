# 朱宸熠 · 作品集网站（手绘粉彩版）

一个 **零依赖、纯静态** 的个人作品集网站，视觉参考插画师 Be-Design 的作品集案例（封面 / 沉浸场景 / 牛皮纸陈列板 / 项目详情四段式结构），内容为真实作品：三维模型、虚幻引擎场景、交互装置、信息可视化、绘本 IP 与展览展板。

> 双击 `index.html` 即可在浏览器打开预览，不需要安装任何环境、不需要打包构建。

- 分类筛选项 = 六个一级目录，「全部」显示全部。
- **五个作品分类**：一个二级项目 = 一张作品卡（一卡一作品，不重复），卡上显示分类、项目名、源文件夹路径、图片/视频数量；分类标题栏显示项目数与素材总数。
- **展板分类**：保留横向相片带，15 张展板各为独立作品，同一栏不出现重复作品。
- 点任意作品卡 / 展板相片打开项目详情弹层：项目说明 → **展示视频** → 图集 → **设计说明**（设计说明取自源文件里的 docx / pptx 原文）。卡片只用一张代表图，避免图片堆砌影响排版。

### 作品卡小精灵

作品卡不再使用涂鸦边框，改为**间隔出现**的小精灵：每隔两张卡放一个，火团子 / 咸蛋黄 / 蓝泡泡三族轮换，由 `main.js → cardMascot()` 按全局计数注入 `.ip-decor__item--card`。

卡片小精灵复用全站小精灵的互动逻辑：悬停显示名字、点击挤压回弹 + 迸粒子 + 台词气泡、鼠标靠近歪头、可拖拽并自动弹回；点击时阻止冒泡，不会误开作品详情。展板相片带不放小精灵，避免轨道克隆后重复出现。
- 每张图的宽高比在 `assets.js` 里以 `ratio` 给出，写进 CSS 变量 `--ar` 由 `aspect-ratio` 控制，因此图片不会被拉伸变形。

### 展板相片带交互（仅展板区）

| 操作 | 效果 |
|------|------|
| 自动 | 相片带持续缓慢漂移，卡片上下错落起伏（`rail-float`），左右边缘渐隐 |
| 鼠标滚轮 | 调节速度：向下加速、向上减速直至反向；停止操作 1.6 秒后缓缓回到基础流速 |
| 按住拖动 | 直接拨动轨道，松手继续漂移；拖拽后不会误触发点击 |
| 悬停 | 该条轨道暂停，卡片放大并浮出标签（展板名称） |
| 点击 | 打开展板详情弹层（15 张完整图集） |
| 触屏 | 可横向拖动查看；系统开启「减少动态效果」时相片带静止，改为可横向滚动 |

## 四、怎么改内容

### 1. 文字与作品信息 → `assets/js/data.js`

全站文案与作品清单都在这个文件里，改完刷新浏览器即可：

| 字段 | 作用 |
|------|------|
| `profile` | 姓名、身份、邮箱、电话、常驻城市（导航 / 页脚 / 联系区自动同步） |
| `cover` | 封面副标题、简介、图片下方的说明文字 |
| `marquee` | 封面下方关键词跑马灯 |
| `filters` | 作品区顶部分类筛选项（= 一级目录名） |
| `categories` | 一级目录：`cat`（目录名）、`label`（显示名）、`desc`（一句话说明）、`projects`（二级项目 id 列表） |
| `projects` | 二级项目：`id` / `title`（子文件夹名）/ `subtitle` / `category` / `folder`（源路径）/ `year` / `meta` / `assets`（对应 assets.js 的键）/ `desc` / `facts[]` / `notes[]` |
| `notes[]` | 设计说明：`{ title, body }`，渲染在弹层底部 |
| `featured` | 精选作品（`project` 指向某个项目 id + 拍立得图片、`ratio`、形状、旋转角度） |
| `skills` / `timeline` / `honors` | 技能标签、履历时间线、获奖与展览 |
| `services` | 「我能做什么」四张卡（`icon` 可选 `model` / `scene` / `brand` / `exhibit`） |
| `contactLinks` / `socials` | 联系方式与页脚社交图标（社交链接待补充） |

加一件作品的流程：把图片放进 `assets/images/works/<分类>/<项目>/` → 在 `assets/js/assets.js` 里登记图片与视频 → 在 `data.js → projects` 里加一个对象（`assets` 字段指向刚登记的键）→ 需要的话在 `categories` 的 `projects` 里挂上 id → 刷新。

### 2. 图片 → `assets/images/works/<分类>/<项目>/`

按源文件夹归位存放，文件名 `01.jpg`、`02.jpg`…，图注写在 `assets/js/assets.js`。
页面会自动替换虚线占位框，**不需要改任何代码**；没有图的地方会显示虚线框 + 提示，方便对照补齐。

`assets.js` 里每个项目有两组图片：
- `images` —— 完整图集，进弹层后全部可见
- `rail` —— 相片带图（仅展板全量使用）；其他分类取 `rail[0]` 作为作品卡封面

### 2.1 视频 → `assets/videos/`

- 统一为 **H.264 (avc1) + AAC、yuv420p、faststart、≤1080p**，浏览器可直接播放。
- 每段视频配一张 `poster-*.jpg` 封面帧，作为播放器首帧画面。
- 在 `assets.js` 里以 `{ src, poster, cap }` 登记，弹层会自动渲染播放器（`preload="none"`，不占流量）。
- 《记忆余烬》作品卡与弹层主视觉改用黑底的 `poster-ember-1.jpg` / `poster-ember-2.jpg`，避免白底或透明底破坏观感。
- 《蜂浪装置》作品卡封面使用 `assets/images/works/interactive/swarm-wave/cover.jpg`（装置主视觉照）。

### 2.2 设计说明 → `data.js → projects[].notes[]`

源文件夹里的 docx / pptx 设计说明已提取为纯文本放入 `notes[]`（含《群生·共振之浪》设计说明原文、《记忆余烬》概念设计原文、《五彩缤纷的世界》剧本摘录）。

### 3. 静态文案（导航 / 关于 / 联系 / 页脚）→ `index.html`

这些是页面骨架文案，直接在 HTML 里改对应段落即可（运行时会被 `data.js` 的 `profile` / `cover` 覆盖的字段除外）。

## 六、动效清单

全部动效写在 `assets/css/style.css` 的 **16. 动效** 区块，逻辑在 `assets/js/main.js` 的 **8. 动效** 模块。

| 动效 | 位置 | 说明 |
|------|------|------|
| 开场遮罩 | 全屏 | 载入时纸色遮罩 + 手绘星芒旋转 + 进度条，完成后 0.7s 擦除 |
| 阅读进度条 | 导航栏底部 | 青绿渐变细线，随滚动实时增长 |
| 标题逐字弹入 | 封面 / 各区块标题 | 字母带旋转弹入，逐字 58ms 递进 |
| 标题手绘波浪线 | 各区块标题下 | SVG 波浪线，纯装饰 |
| 关键词跑马灯 | 封面与精选之间 | 深色底 + 关键词横向滚动，鼠标悬停暂停 |
| 手绘圈注 | 关于我 / 联系 | SVG 椭圆圈住关键词，滚动进入时「画」出来 |
| 鼠标视差 | 封面装饰层 | 星芒、草叶随鼠标分层位移（`data-depth` 控制幅度） |
| 滚动视差 | 精选场景层 | 光斑与树叶随滚动上下错位（`data-scroll` 控制幅度） |
| 卡片 3D 倾斜 | 拍立得 / 作品 / 服务卡 | 跟随鼠标轻微 rotateX / rotateY |
| 图片推近 | 作品卡 hover | 卡片内图片放大 1.07 倍 |
| 磁吸按钮 | 封面 CTA | 按钮朝鼠标方向轻微吸附 |
| 笔触光标 | 全局 | 墨点 + 圆环双层跟随，悬停可点元素时圆环放大；输入框内保留系统光标 |
| 滚动进场 | 所有区块 | IntersectionObserver 进场淡入上移 |
| IP 小精灵待机 | 全站背景 + 部分作品卡 | 三族三种性格：火团子急躁抖动、咸蛋黄果冻晃动、蓝泡泡缓慢漂浮（`ip-idle-*`） |
| IP 小精灵反应 | 全站背景 + 部分作品卡 | 鼠标靠近 210px 内触发 `ip-react-*`，放大 1.12 倍并歪头看向光标 |
| IP 小精灵点击 | 全站背景 + 部分作品卡 | 挤压回弹 `ip-pop` + 迸出 8 颗粒子（蓝色为环形泡泡）+ 台词气泡 |
| IP 小精灵拖拽 | 全站背景 + 部分作品卡 | 按住拖动会跟随指针并按方向倾斜，松手 0.6s 弹回原位 |
| 展板相片带漂移 | 展板区 | 15 张展板横向持续漂移，卡片上下错落起伏（`rail-float`） |

**想加/减动效：**

- 关闭某个效果 → 删掉 HTML 上对应的 `data-depth` / `data-scroll` / `split` / `mark` 属性
- 调幅度 → 改 `data-depth`（0–1）、`data-scroll`（0–1）的数值
- 整站关掉动效 → 系统开启「减少动态效果」时自动全部关闭（已适配 `prefers-reduced-motion`）

## 八、部署

纯静态，直接把整个文件夹传到任意静态托管即可：

- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支根目录
- **Vercel / Netlify**：导入文件夹，构建命令留空，输出目录填 `.`
- **本地预览**：直接双击 `index.html`（若浏览器拦截脚本，可用 `npx serve .` 启动本地服务）

## 九、待补充 / 后续可扩展
