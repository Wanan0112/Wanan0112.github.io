# 朱宸熠 · 作品集网站（手绘粉彩版）

一个 **零依赖、纯静态** 的个人作品集网站，视觉参考插画师 Be-Design 的作品集案例（封面 / 沉浸场景 / 牛皮纸陈列板 / 项目详情四段式结构），内容为真实作品：三维模型、虚幻引擎场景、交互装置、信息可视化、绘本 IP 与展览展板。

> 双击 `index.html` 即可在浏览器打开预览，不需要安装任何环境、不需要打包构建。

---

## 三、作品分类与排版规则

| 分区 | 数据来源 | 内容 | 排版 |
|------|----------|------|------|
| 精选作品 | `data.js → featured` | 风格化石头刀、硬表面工业箱体、自然森林场景、恋语花坊 | 沉浸场景里 4 张悬浮拍立得 |
| 三维模型设计 | `works` 中 `category: '三维模型'` | 石头刀 / 工业箱体 / 机器人厨师 | 混合比例拼贴墙 |
| 虚幻引擎设计 | `category: '虚幻引擎'` | 森林场景 ×2、恋语花坊 ×2 | 混合比例拼贴墙 |
| 交互装置设计 | `category: '交互装置'` | 电子绦虫 ×3 | 混合比例拼贴墙 |
| 信息可视化设计 | `category: '信息可视化'` | 本色共生、记忆余烬动态海报 ×2 | 混合比例拼贴墙 |
| 绘本 IP 设计 | `category: '绘本 IP'` | 五彩缤纷的世界 ×5 | 混合比例拼贴墙 |
| **主题海报设计** | `data.js → posters` | 12 张展览 / 课程展板 | 竖版 2:3，4 列单独成区，不参与上方筛选 |

- 分类筛选只作用于上方 5 个专业分组，**主题海报设计**永远显示在独立板块。
- 每张图在 `data.js` 里的 `ratio`（宽 ÷ 高）会写进 CSS 变量 `--ar`，由 `aspect-ratio` 控制图位，因此图片不会被拉伸变形，也不会被裁掉。

## 四、怎么改内容

### 1. 文字与作品信息 → `assets/js/data.js`

全站文案与作品清单都在这个文件里，改完刷新浏览器即可：

| 字段 | 作用 |
|------|------|
| `profile` | 姓名、身份、邮箱、电话、常驻城市（导航 / 页脚 / 联系区自动同步） |
| `cover` | 封面副标题、简介、图片下方的说明文字 |
| `marquee` | 封面下方关键词跑马灯 |
| `filters` | 作品区顶部分类筛选项 |
| `groups` | 全部作品的分组顺序与分组标题 |
| `featured` | 精选作品（标题、客户、分类、年份、图片、`ratio`、形状、旋转角度、`detail` 详情） |
| `works` | 上方 5 个专业分组的全部作品（`id` / `title` / `category` / `meta` / `image` / `ratio`） |
| `posters` | 主题海报设计区的展板作品 |
| `skills` / `timeline` / `honors` | 技能标签、履历时间线、获奖与展览 |
| `services` | 「我能做什么」四张卡（`icon` 可选 `model` / `scene` / `brand` / `exhibit`） |
| `contactLinks` / `socials` | 联系方式与页脚社交图标（社交链接待补充） |

加一件作品的流程：把图片放进 `assets/images/works/` → 在 `works`（或 `posters`）数组里加一个对象 → 填好 `image` 与 `ratio` → 刷新。

### 2. 图片 → `assets/images/`

按 `assets/images/README.md` 里的命名放进去，页面会自动替换虚线占位框，**不需要改任何代码**。
没有图的地方会显示虚线框 + 文件名提示，方便对照补齐。

### 3. 静态文案（导航 / 关于 / 联系 / 页脚）→ `index.html`

这些是页面骨架文案，直接在 HTML 里改对应段落即可（运行时会被 `data.js` 的 `profile` / `cover` 覆盖的字段除外）。

## 五、改配色 / 字体

全部集中在 `assets/css/style.css` 顶部的 **00. 主题令牌**：

```css
--ink: #23414c;      /* 主文字色 */
--paper: #fbf5e8;    /* 纸底色 */
--kraft: #d9c19b;    /* 牛皮纸色 */
--aqua: #8fd9e0;     /* 封面青绿 */
--leaf: #a9d48f;     /* 叶片绿 */
--sun: #f7e9b8;      /* 星芒米黄 */
--sky: #7fb2e6;      /* 联系区蓝 */
```

改这几个变量，整站配色会一起变。字体在 `--font-display`（标题衬线）/ `--font-body`（正文）/ `--font-mono`（标签）里改。

## 六、动效清单

全部动效写在 `assets/css/style.css` 的 **16. 动效** 区块，逻辑在 `assets/js/main.js` 的 **8. 动效** 模块。

| 动效 | 位置 | 说明 |
|------|------|------|
| 开场遮罩 | 全屏 | 载入时纸色遮罩 + 手绘星芒旋转 + 进度条，完成后 0.7s 擦除 |
| 阅读进度条 | 导航栏底部 | 青绿渐变细线，随滚动实时增长 |
| 标题逐字弹入 | 封面 / 各区块标题 | 字母带旋转弹入，逐字 58ms 递进 |
| 标题手绘波浪线 | 各区块标题下 | SVG 波浪线，纯装饰 |
| 关键词跑马灯 | 封面与精选之间 | 深色底 + 关键词横向滚动，鼠标悬停暂停 |
| 手绘圈注 | 关于我 / 联系 | SVG 椭圆圈住关键词，滚动进入时「画」出来 |
| 鼠标视差 | 封面装饰层 | 星芒、草叶随鼠标分层位移（`data-depth` 控制幅度） |
| 滚动视差 | 精选场景层 | 光斑与树叶随滚动上下错位（`data-scroll` 控制幅度） |
| 卡片 3D 倾斜 | 拍立得 / 作品 / 服务卡 | 跟随鼠标轻微 rotateX / rotateY |
| 图片推近 | 作品卡 hover | 卡片内图片放大 1.07 倍 |
| 磁吸按钮 | 封面 CTA | 按钮朝鼠标方向轻微吸附 |
| 笔触光标 | 全局 | 墨点 + 圆环双层跟随，悬停可点元素时圆环放大；输入框内保留系统光标 |
| 滚动进场 | 所有区块 | IntersectionObserver 进场淡入上移 |
| IP 小精灵待机 | 全站背景 | 三族三种性格：火团子急躁抖动、咸蛋黄果冻晃动、蓝泡泡缓慢漂浮（`ip-idle-*`） |
| IP 小精灵反应 | 全站背景 | 鼠标靠近 210px 内触发 `ip-react-*`，放大 1.12 倍并歪头看向光标 |
| IP 小精灵点击 | 全站背景 | 挤压回弹 `ip-pop` + 迸出 8 颗粒子（蓝色为环形泡泡）+ 台词气泡 |
| IP 小精灵拖拽 | 全站背景 | 按住拖动会跟随指针并按方向倾斜，松手 0.6s 弹回原位 |

**想加/减动效：**

- 关闭某个效果 → 删掉 HTML 上对应的 `data-depth` / `data-scroll` / `split` / `mark` 属性
- 调幅度 → 改 `data-depth`（0–1）、`data-scroll`（0–1）的数值
- 整站关掉动效 → 系统开启「减少动态效果」时自动全部关闭（已适配 `prefers-reduced-motion`）

## 七、已有交互

- 分类筛选（点击标签过滤 5 个专业分组，主题海报设计区不受影响）
- 项目详情弹层（ESC 关闭、点背景关闭、上一个/下一个、左右分栏图集）
- 图片灯箱（方向键切换、ESC 关闭）
- 导航当前区块高亮 + 移动端抽屉菜单
- 表单提交提示 Toast（未接后端，引导邮件联系）
- IP 小精灵互动（悬停显示名字气泡、点击弹台词 + 迸粒子、鼠标靠近歪头、可以拖着玩并自动弹回）
- 完全响应式：1440 / 1080 / 900 / 640 四个断点（≤900px 收起小精灵，避免遮挡正文）

## 八、部署

纯静态，直接把整个文件夹传到任意静态托管即可：

- **GitHub Pages**：推到仓库 → Settings → Pages → 选分支根目录
- **Vercel / Netlify**：导入文件夹，构建命令留空，输出目录填 `.`
- **本地预览**：直接双击 `index.html`（若浏览器拦截脚本，可用 `npx serve .` 启动本地服务）

## 九、待补充 / 后续可扩展

- 社交链接：`data.js → socials` 里微博 / 小红书 / 站酷 / GitHub 的 `href` 目前是 `#`，填上真实地址即可

- 深色模式：在 `:root` 增加一组变量，用 `[data-theme='dark']` 切换
