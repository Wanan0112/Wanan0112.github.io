# 安星 App 原型

根据《安星·夜行安全App设计说明书》与 6 张参考效果图制作的高保真可交互 Web 原型。采用原生 HTML / CSS / JavaScript，无需构建步骤。

## 预览

直接打开 `index.html`，或在本目录运行 `npm start` 后访问本地服务地址。

## 页面与交互

- **启动加载**：品牌 Logo 启动页，加载时尝试获取实时位置，首次进入展示登录页，可跳过。
- **登录**：手机号 + 演示验证码登录、昵称修改、退出登录，状态保存在本机。
- **主题色设定**：薄荷夜色 / 琥珀暖光 / 星蓝守护三套强调色，地图点位颜色/形状/光晕、SOS 倒计时、定位跟随、雷达扫描、语音提醒均可设置并持久化。
- **导航首页（三态极简）**：默认态仅保留全屏 Leaflet 地图、顶部通栏搜索框与右侧图层 / 风险 / 定位悬浮按钮；搜索到达后从底部弹出半屏毛玻璃路线面板（安全系数、路灯覆盖、监控数量、避暗巷提示、AI 全程陪伴开关、SOS 与开始导航）；点击开始导航后面板收起，进入只保留路线、方向指引与 SOS 的纯导航地图模式。面板支持上滑展开、下滑关闭。
- **搜索目的地弹窗**：默认展示输入栏、常用地址与历史搜索（最多保留 6 条，可单条删除或清空）；上滑弹窗后展开推荐地点，优先展示附近警务站等安全守护点，再展示高评分景点、美食与交通枢纽。推荐项按当前位置估算距离，点击即可规划路线并写入历史。
- **路线安全分析**：Photon 地点搜索 + OSRM 真实路线规划（失败时降级为演示路线），三条路线对比、地图路线高亮、安全分解释、分享行程；长按路线卡可收藏。
- **地图导航**：真实 GPS 位置跟随、方向罗盘、路线高亮、照明不足区域语音提醒（需浏览器支持）。
- **地图设置**：图层按钮可切换 2D / 3D 视角与标准 / 卫星底图，取消按钮可关闭弹层；风险按钮弹出附近夜行事件轻弹窗；定位按钮回到当前位置。导航页左上角显示实时气温与天气。
- **全局入口**：首页默认态保留底部标签栏，可直接切换导航 / 伴行 / SOS / 社区 / 我的；路线面板与导航中状态会隐藏标签栏保证地图视野。另可从屏幕左边缘右滑呼出功能抽屉，进入路线分析、AR 眼镜等入口。
- **一键报警**：点击底部 SOS 进入 3 秒确认，长按取消；报警状态逐条更新，长按 2 秒取消报警。
- **伴行**：接入在线 MP3 音源与 Pexels 公开 MP4 视频，支持播放/切歌/进度/音量、歌词同步、视频在线播放与歌单切换。
- **社区**：推荐/关注/同城筛选、话题与好物、点赞、发布故事。
- **AR 眼镜控制台**：模式切换、安全感知开关、开放式音频、查找眼镜。
- **我的**：紧急联系人、安全路线、守护记录；提供独立的设置页入口、问题反馈入口，以及切换账号与退出登录。
- **独立设置页**：点击“我的 → 设置”进入单独页面，分为个性设置（外观与主题、管理语言）、安全隐私设置（隐私与权限、账号与安全）、其他设置（关于安星、AR 眼镜设备、问题反馈）。支持简体中文 / English 切换。
- **隐私与权限**：提供允许他人访问我的主页、隐藏购买记录、位置权限、匿名体验改进四项开关，每项带说明文字并保存在本机；退出登录前会弹出确认提示。
- **问题反馈**：可选择问题类型、填写描述并提交，也可进入在线客服演示会话联系客服。
- **导航进行中**：转向卡逐步更新、里程与剩余时间变化、行程分享、SOS 快捷入口。

移动端支持刘海安全区、触控优化、下拉关闭弹层与横屏提示。

## 目录

```
index.html          页面骨架与图标
styles/             设计系统、页面样式、响应式与移植功能样式
scripts/            页面模板与交互逻辑（legacy.js 为旧版能力移植层）
vendor/             Leaflet 地图库
assets/             从设计稿裁切的预览图与 Logo
```

> 地图瓦片、地点搜索与路线规划来自公开服务；路灯、监控、安全分与事件统计为推演演示数据，不代表真实城市设施。涉及 110 呼叫与位置共享的功能仅为体验设计。旧版 NightGuard 的地图导航、主题设定、登录与加载逻辑已移植到新版视觉体系中。
