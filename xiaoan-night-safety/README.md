# 小安 · 夜行安全 App 原型

根据《小安·夜行安全App设计说明书》与 6 张参考效果图制作的高保真可交互 Web 原型。采用原生 HTML / CSS / JavaScript，无需构建步骤。

## 预览

直接打开 `index.html`，或在本目录运行 `npm start` 后访问本地服务地址。

## 页面与交互

- **启动加载**：品牌 Logo 启动页，加载完成后自动进入首页。
- **导航首页**：搜索目的地（支持输入筛选）、安全分构成、路灯图层、实时事件、常用地址、AI 建议、开始安全导航；长按导航键可快速分享行程。
- **路线安全分析**：三条路线对比、地图路线高亮、安全分解释、分享行程；长按路线卡可收藏。
- **一键报警**：点击底部 SOS 进入 3 秒确认，长按取消；报警状态逐条更新，长按 2 秒取消报警。
- **娱乐**：音乐播放/切歌/进度/音量、歌词同步、视频后台播放、歌单切换。
- **社区**：推荐/关注/同城筛选、话题与好物、点赞、发布故事。
- **AR 眼镜控制台**：模式切换、安全感知开关、开放式音频、查找眼镜。
- **我的**：紧急联系人、安全路线、守护记录、隐私权限等设置入口。
- **导航进行中**：转向卡逐步更新、里程与剩余时间变化、行程分享、SOS 快捷入口。

移动端支持刘海安全区、触控优化、下拉关闭弹层与横屏提示。

## 目录

```
index.html          页面骨架与图标
styles/             设计系统、页面样式、响应式
scripts/            页面模板与交互逻辑
assets/             从设计稿裁切的预览图与 Logo
```

> 所有路灯、事件、安全分与报警数据均为概念演示数据，不代表真实能力。涉及 110 呼叫与位置共享的功能仅为体验设计。
